# «Из нищеты в миллиардеры» — Android офлайн-проект

Игра встроена в `app/src/main/assets/index.html` и загружается локально через Android WebView. В манифесте намеренно нет разрешения INTERNET: приложение не требует хостинга и для запуска не нуждается в подключении к сети. Внешние веб-шрифты/ресурсы, если они используются HTML, могут не загружаться офлайн.

## Как собрать APK

1. Установи Android Studio на компьютер: https://developer.android.com/studio
2. Распакуй ZIP и открой в Android Studio папку `Миллиардеры_Android_проект` (в ней находится `settings.gradle`).
3. Дождись синхронизации Gradle. Для сборки потребуется интернет на компьютере, чтобы Android Studio загрузила Gradle и Android SDK компоненты.
4. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. После успешной сборки нажми **locate** в уведомлении. APK обычно находится в `app/build/outputs/apk/debug/app-debug.apk`.
6. Передай APK на Android-телефон, открой файл и разреши установку из этого источника, если система спросит.

## Важно

Это исходный проект Android Studio, не готовый APK. В текущей среде Android SDK и Gradle отсутствуют, поэтому собрать и протестировать APK здесь не удалось. Проверь игру на телефоне после сборки. Игровой прогресс будет сохраняться только если сама HTML-игра использует `localStorage` или иной локальный механизм сохранения.
